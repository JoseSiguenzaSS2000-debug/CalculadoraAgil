# Actividad semana 7 - CalculadoraAgil

## Reflexión breve

En este mini-proyecto se desarrolló una calculadora básica en C# y se aplicaron prácticas de calidad relacionadas con el desarrollo ágil, además se utilizó visual studio insider para complementar el manejo de otras asignaturas.

### 1 Coding Standards

Se configuró un archivo `.editorconfig` para establecer reglas de formato y estilo del código C#. Esta práctica ayuda a mantener una estructura uniforme, facilita la lectura y reduce errores o diferencias de formato entre desarrolladores.

### 2 Pull Request y Code Review

Se creó la rama mejora calculadora, donde se realizó un cambio al programa para agregar el mensaje final en el cual se agradece por utilizar dicha calculadora (un mensaje breve y sencillo). Después se hizo un commit y se envió la rama a GitHub mediante un Pull Request.

El cambio fue revisado mediante un Code Review al instante, dejando un comentario sobre la modificación. Finalmente, el Pull Request fue revisado y se integró a la rama master` sin obtener errores, problemas o conflictos. Después se eliminó la rama de trabajo para mantener el orden y limpieza.

### 3 Problemas que se evitan

Estas prácticas ayudan a evitar errores de estilo, cambios difíciles de integrar y retrabajo. Trabajar mediante ramas y Pull Requests permite revisar los cambios antes de incorporarlos al código principal. Además, en un proyecto sencillo puede que no sea tan llamativo, sin embargo al momento de realizar un trabajo de mayor magnitud, se puede observar la importancia de estos metodos y así no interferir con cambios en la rama principal.

### 4  Relación con lo visto en clase

El flujo utilizado se relaciona con el desarrollo ágil porque permite integrar cambios pequeños y revisados de forma frecuente(con el code review de por medio), Esto reduce el riesgo de llegar a una integración tardía o a un famoso Big Bang donde muchos cambios se juntan al final y resulta más difícil detectar y corregir problemas.

En conclusión, aunque el proyecto es pequeño, el proceso permitió aplicar un flujo de trabajo ordenado con respectivo paso a paso, modificando como si fuese una simulación de proyecto real y considero que es una práctica muy recomendable para compaginar con otras asignaturas en las cuales se desarrollan proyectos mas complejos.
